# Call Centre Executive Dashboard

## Project Overview

This Power BI dashboard provides an executive-level overview of call centre performance, combining operational metrics, agent productivity, service quality, and customer satisfaction into a single interactive report.

The dashboard was designed to help managers and senior stakeholders monitor call handling performance, identify service bottlenecks, compare agent-level results, and track customer experience trends across different call topics and time periods.

## Key Objectives

- Monitor call centre performance using clear KPI indicators.
- Track answered calls, resolved calls, average answer speed, and average satisfaction rating.
- Compare agent performance across key operational metrics.
- Analyse monthly call volumes and resolution trends.
- Identify topics generating the highest call demand.
- Support faster decision-making through interactive filters and executive visuals.

## Dashboard Features

### Executive KPI Summary

The dashboard includes high-level KPI cards and gauge visuals for:

- Average Answer Speed (AAS)
- Number of Answered Calls
- Number of Resolved Calls
- Average Satisfaction Rating (ASR)

These indicators provide a quick view of overall service performance and operational efficiency.

### Agent Performance Analysis

The report compares individual agents based on:

- Number of calls answered
- Number of resolved calls
- Average answer speed
- Average satisfaction rating
- Average handling time

This helps managers identify high-performing agents, coaching opportunities, and workload distribution patterns.

### Call Volume and Resolution Tracking

The dashboard tracks call activity by month and resolution status, allowing users to understand:

- Monthly call trends
- Answered versus unresolved calls
- Resolution performance over time
- Seasonal or operational changes in call demand

### Topic-Level Insights

The report includes topic-based analysis showing call volumes and satisfaction scores across areas such as:

- Streaming
- Technical Support
- Payment related queries
- Admin Support
- Contract related queries

This helps identify which service areas are creating the most demand and where customer satisfaction may need improvement.

### Interactive Filtering

The dashboard includes slicers for:

- Agent
- Topic
- Date range
- Resolution status

These filters allow users to drill down into specific operational areas and perform focused analysis.

## Tools and Techniques Used

- Interactive slicers

## Key Metrics Included

| Metric | Description |
|---|---|
| Answered Calls | Total number of calls answered by agents |
| Resolved Calls | Total number of calls successfully resolved |
| Average Answer Speed | Average time taken to answer calls |
| Average Satisfaction Rating | Customer satisfaction score based on call experience |
| Average Handle Time | Average time spent handling each call |
| Resolution Status | Whether the call was resolved or not |
| Agent Performance | Comparison of call centre agents across operational KPIs |

## Business Value

This dashboard enables call centre leaders to move from static reporting to interactive performance monitoring. It provides a clear view of service efficiency, customer satisfaction, and agent productivity, helping the organisation make better decisions around staffing, training, workload balancing, and process improvement.

The report can support regular performance reviews, operational meetings, service improvement initiatives, and executive-level reporting.

## Example Insights

From the dashboard, stakeholders can quickly identify:

- Which agents answer and resolve the highest number of calls.
- Which topics generate the most customer contact.
- Whether satisfaction ratings are improving or declining over time.
- How monthly call volumes change across the reporting period.
- Where average answer speed or handling time may require improvement.
