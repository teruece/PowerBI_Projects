# Call Centre Executive Dashboard

## Project Overview

This Power BI dashboard provides an executive-level overview of call centre performance, combining operational metrics, agent productivity, service quality, and customer satisfaction into a single interactive report.

The dashboard was designed to help managers and senior stakeholders monitor call handling performance, identify service bottlenecks, compare agent-level results, and track customer experience trends across different call topics and time periods.

## Key Objectives

- Monitor call centre performance using clear KPI indicators.
- Track answered calls, resolved calls, average answer speed, and average satisfaction rating.
- Compare agent performance across key operational metrics.
- Analyse monthly call volumes and resolution trends.
- Identify topics generating the highest call demand.
- Support faster decision-making through interactive filters and executive visuals.

## Dashboard Features

### Executive KPI Summary

The dashboard includes high-level KPI cards and gauge visuals for:

- Average Answer Speed (AAS)
- Number of Answered Calls
- Number of Resolved Calls
- Average Satisfaction Rating (ASR)

### Agent Performance Analysis

The report compares individual agents based on answered calls, resolved calls, average answer speed, average satisfaction rating, and average handling time.

### Topic-Level Insights

The report analyses call volumes and satisfaction scores across areas such as Streaming, Technical Support, Payment-related queries, Admin Support, and Contract-related queries.

### Interactive Filtering

The dashboard includes slicers for Agent, Topic, Date Range, and Resolution Status.

## Tools and Techniques Used

## Business Value

This dashboard helps call centre leaders move from static reporting to interactive performance monitoring. It provides a clear view of service efficiency, customer satisfaction, and agent productivity, supporting better decisions around staffing, coaching, workload balancing, and process improvement.
